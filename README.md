# O problema que vamos investigar 
As apostas digitais aproximaram jogos de azar, publicidade, meios de pagamento e uso cotidiano do celular. Entre esses produtos estão as máquinas de rolos, popularizadas no Brasil pelo chamado “jogo do tigrinho”. Seus símbolos e animações podem tornar uma rodada fácil de acompanhar, mas não explicam, por si, a probabilidade de receber um prêmio nem o resultado financeiro de repetir o jogo. 

Neste trabalho, a turma construirá uma **máquina didática com regras públicas**. Ela permitirá calcular probabilidades, executar simulações e confrontar impressões com dados. O objetivo é compreender a matemática do produto e usar essa compreensão em uma discussão fundamentada sobre saúde, renda, tecnologia e políticas públicas.
